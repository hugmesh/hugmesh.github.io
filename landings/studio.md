The Studio is a desktop app for Windows and Linux. It puts the HugMesh build scripts
behind a wizard and runs a local mesh from the system tray.

Its build menu has ten cards. Three build an image: Mesh node, Mesh desktop client and
Standalone Gentoo desktop. The other seven run a tool: Local Docker mesh, Mesh emulation,
Cloud deploy, MDM phone, MDM Quest headset, Run e2e tests and Create nodes for local
cloud.
