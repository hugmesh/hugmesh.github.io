There are three ways to run HugMesh: try it on one computer with Docker, build a mesh on
your own hardware, or join a mesh someone else runs.

The main path below covers your own hardware, in order, and each step ends with a check
that it worked. The packaged Studio builds images with Docker and can generate each
node's keys. Of the packages, the Linux tarball can also write an image to a device; the
Flatpak and the Windows MSI cannot. A KEYS stick is written with a script from a
checkout. [Install the Studio](/studio/installers) explains the difference.

To join an existing mesh instead, see
[Join from a Linux or Windows computer with Docker](/operations/docker-mesh-node), or the
[client images](/devices/client-images) under Devices.
