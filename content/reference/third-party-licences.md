HugMesh is MIT licensed. A few repositories also carry third-party art, models or code
under their own licences. Each one keeps an attribution file next to the material, and
that file is the record: it names every item, its source and its licence.

| Repository | What | Licence | Attribution file |
|---|---|---|---|
| `hugmesh-matrix-ui` | MediaPipe Face Landmarker model and runtime, for camera face tracking in the 3D chat room. Served from the mesh itself, with no CDN. | Apache-2.0 | [`projects/matrix/src/assets/mediapipe/README.md`](https://github.com/hugmesh/hugmesh-matrix-ui/blob/main/projects/matrix/src/assets/mediapipe/README.md) |
| `hugmesh-generator` | Configuration and templates from the Headwind MDM Docker image, used to build the MDM server. | Apache-2.0 | [`specs/cluster/manifests/headwind/docker/README.md`](https://github.com/hugmesh/hugmesh-generator/blob/main/specs/cluster/manifests/headwind/docker/README.md) |
| `hugmesh-games` | Ground and wall textures for the RPG maker's biomes, from ambientCG. No attribution required. | CC0 1.0 | [`rpg-builder/src/main/resources/biome-assets/LICENSES.md`](https://github.com/hugmesh/hugmesh-games/blob/main/rpg-builder/src/main/resources/biome-assets/LICENSES.md) |
| `hugmesh-games` | Godot add-ons, models and textures in the Character Forge project. | MIT, CC0 and CC-BY | [`games/character-forge/THIRD_PARTY_ASSETS.md`](https://github.com/hugmesh/hugmesh-games/blob/main/games/character-forge/THIRD_PARTY_ASSETS.md) |

## Rules for adding material

- Only material with a licence that allows redistribution goes into a repository. The
  Character Forge project limits itself to CC0, CC-BY and MIT.
- Add the item to the repository's attribution file in the same change, with its
  source and licence.
- Material under CC-BY carries its attribution string exactly as the licence requires;
  the D&D SRD catalogue quotes the required string.
