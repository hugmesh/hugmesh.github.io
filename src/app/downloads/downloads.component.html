Get HugMesh Studio

Or run it from a checkout

Studio needs no installer to run. From a hugmesh-generator checkout: 

cd studio
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
./hugmesh-studio            # Windows: hugmesh-studio.bat

The installers exist so the app is available to people who do not want a Python environment — they package the same code.
