Or run Studio from a checkout

Studio needs no installer to run. From a hugmesh-generator checkout: 

cd studio
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
./hugmesh-studio            # Windows: hugmesh-studio.bat

The installers exist for people who do not want a Python environment. They package the same code. They do not package a hugmesh-generator checkout: start an installed Studio with --generator-dir <path>. Building images needs Docker, or a Gentoo host for a native build. See the Studio documentation.
